# Vaccination Slot Booking & Tracking Platform

A full-stack web application for managing vaccination centers, vaccination slots, and user appointments.

## Project Overview

The platform allows users to securely register, log in, view available vaccination slots, book appointments, and track their booking status.

Administrators can manage vaccination centers, vaccines, vaccination slots, and user bookings.
